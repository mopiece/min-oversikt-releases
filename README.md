# Min Oversikt – oppdateringer

Dette offentlige prosjektet inneholder kun signerte utgivelser og oppdateringsfilen som Min Oversikt leser.

- Last ned nyeste versjon under [Releases](https://github.com/mopiece/min-oversikt-releases/releases).
- I appen kan du velge **Min Oversikt → Se etter oppdateringer…**.
- Appen spør før en ny versjon installeres.
- Tidligere publiserte versjoner blir liggende under Releases, slik at de kan lastes ned igjen.

Kildekoden ligger separat i et privat prosjekt.
